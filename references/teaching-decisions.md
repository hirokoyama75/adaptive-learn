# Small decisions inside a learning block

Use when a response is ambiguous or adaptation is not helping. Do not print this checklist as a ritual.

| What happened | Smallest useful response | Do not conclude |
| --- | --- | --- |
| Correct result with no visible reasoning | Accept the result; ask for a discriminating step only if guessing or a hidden misconception would materially change what comes next. | Every correct result needs an interrogation. |
| Correct after the method was named | Credit execution; later test selecting the method if that is a target. | Independent method selection was established. |
| Correct after a worked example | Credit assisted progress; fade toward a comparable independent task, then revisit after a gap. | Immediate imitation proves retention. |
| One arithmetic/syntax slip in otherwise sound reasoning | Point to the local discrepancy or ask for a quick check. | All foundations are weak. |
| Cannot start | Demonstrate a first move or complete an example, then leave a manageable continuation. | More unsupported guesses will diagnose everything. |
| Fluent explanation, failed new-case application | Locate the missing connection or selection difficulty; model only that move. | Eloquence proves competence. |
| Slow but correct | Preserve independence; ask about pace only if helpful. | Time spent typing means low ability. |
| Learner challenges feedback | Recheck conditions, equivalence, sources, and the task itself. Correct yourself when warranted. | The learner is confidently wrong. |
| Explanation itself introduced unfamiliar words | Define one necessary term concretely and restate the blocked step. | Another prerequisite lesson is always needed. |
| Many due reviews | Suggest a small relevant selection at a break; respect the chosen goal/budget. | All overdue work must come first. |

## Decide when to stop or move on

Before practice, know what task-appropriate evidence would support the next step. It may be a valid construction, justified distinction, supported interpretation, or successful independent performance—not always a verbal explanation.

When that evidence exists, move on provisionally and retain a later-review obligation for important targets. If the task is still assisted, either fade help or explain the risk of a requested skip. If uncertainty remains but more probing would not change the next action, start the useful action rather than diagnosing forever. Stop when the learner's agreed task/budget is reached or they ask to stop; save the unfinished task honestly.

## Tutor correction example

Task: simplify `2(x + 1)`. Learner: `2x + 2`. Tutor incorrectly expected `2x + 1`.

Say: “Your answer was correct. I failed to distribute the 2 to both terms.” Remove the false misconception from the active checkpoint; invalidate the misgraded evidence with a reason. If recording corrected performance, retain the original observation time and conditions—this regrade is not another attempt or later retrieval. Rebuild the review from valid evidence. If the incorrect rule was saved as a reusable claim, withdraw it, add the correct qualified claim under a new ID, and inspect dependent records. Do not silently edit history or merely append an apology while leaving the false error active.
