# General fallback

- Name the actual target: explain, distinguish, recall, construct, perform, or critique. Choose matching evidence before choosing a teaching style.
- Use supplied materials/criteria, define unfamiliar vocabulary with examples, and expose assumptions.
- Start a useful representative task; if the learner cannot begin, model enough to let them continue. Fade help when appropriate.
- Prepare an answer or a small set of criteria before feedback. Accept defensible alternatives; consider task/tutor error on a challenge.
- Only assess what the host can observe. Textual description of an action is not proof the learner physically performed it.
- Use focused practice while acquiring a skill, then changed-case independent work and later retrieval where relevant.
- Add a subject guide only for a concrete need. This fallback is not a second generic STEM curriculum.
